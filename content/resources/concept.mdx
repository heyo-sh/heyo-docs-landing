# Concept

Heyo Docs is an open-source documentation project designed to grow in the
open. The goal is to keep adding useful components - from simple building
blocks to more ambitious, fancy experiences.

We want to explore documentation UI that is not available out of the box in
alternatives such as Fumadocs or Mintlify, while keeping every component easy
to understand, adapt, and contribute back to.
